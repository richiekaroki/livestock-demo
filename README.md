# 🚀 Livestock Management Demo - Full-Stack Showcase

> **Built by Richard** · React/TypeScript Full-Stack Demo

## 🎯 What This Demo Proves

**"I can build scalable livestock management technology"**

This is a **production-ready prototype** demonstrating modern full-stack development with React 19, TypeScript, and enterprise-grade architecture.

## 🛠 Tech Stack

### Frontend

- **React 19** with TypeScript for type safety
- **Tailwind CSS v4** for rapid, consistent UI development
- **React Leaflet** for geographic data visualization
- **Recharts** for interactive analytics and charts
- **React Router v7** for navigation

### Development

- **Vite 7** for fast builds and development
- **ESLint** for code quality
- **TypeScript 5.9** for robust development

## 📱 Features Demonstrated

- ✅ **Animal Registration** - Complete CRUD operations
- ✅ **Health Tracking** - Real-time status monitoring
- ✅ **Interactive Maps** - Geographic data visualization
- ✅ **Advanced Filtering** - Multi-criteria search
- ✅ **Responsive Design** - Mobile-first approach
- ✅ **Dark/Light Theme** - System-aware theming
- ✅ **Real-time Updates** - Live data simulation

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
